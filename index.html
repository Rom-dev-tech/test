🔄 Базові анімації

Базові анімації

Spin - обертання елемента

Bounce - підскакування вгору-вниз

Pulse - пульсування (збільшення-зменшення)

animation: spin 2s linear infinite;

➡️ Slide анімації

Зліва

slideInLeft

Справа

slideInRight

Знизу

slideInUp

Slide анімації

Елементи з'являються з різних сторін екрана

Можна додавати затримку (animation-delay)

animation: slideInLeft 1s ease-out;

Hover анімації

Спрацьовують при наведенні миші

Роблять інтерфейс живим та інтерактивним

.card:hover { animation: wiggle 0.5s; }

🎯 Складні анімації

Складні анімації

Комбінування кількох анімацій разом

Використання animation-delay для послідовності

animation: float 3s ease-in-out infinite;
