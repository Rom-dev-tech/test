🖼️ Фонові vs Контентні зображення

🎯 Основна різниця

🎨 Фонове зображення

CSS background-image

CSS властивість:

background-image: url('image.jpg');
background-size: cover;
background-position: center;

📄 Контентне зображення

HTML тег:

<img src="image.jpg" alt="Опис">

📏 Background-size властивості

📐 Cover (покриває повністю)

background-size: cover

📦 Contain (вміщується повністю)

background-size: contain

🔄 Repeat (повторення)

background-repeat: repeat

🎛️ Object-fit для <img>

✂️ Cover (обрізає)

📋 Contain (вміщує)

💼 Практичні приклади

🌟 Hero секція (фонове зображення)

Вітаємо!
Фонове зображення ідеально для hero секцій

📰 Стаття (контентне зображення)

Заголовок статті

Контентні зображення ідеально підходять для статей, галерей, продуктів. Вони є частиною контенту і мають семантичне значення.

🤔 Коли використовувати?

🎨 Фонові зображення

Використовуй коли:

  • Декоративні елементи
  • Hero секції
  • Фони карток
  • Паттерни і текстури
  • Не потрібен alt текст
💡 Фон = Дизайн, не контент!

📄 Контентні зображення

Використовуй коли:

  • Зображення товарів
  • Фото в статтях
  • Аватари користувачів
  • Логотипи
  • Потрібен alt текст
💡 Контент = Інформація для користувача!

🎮 Інтерактивна демонстрація

Фонове зображення

Декоративне, не має семантичного значення

📋 Підсумок

Головні відмінності:

🎨 Фонові:

  • CSS background-image
  • Декоративні
  • Контролюються CSS
  • Без alt тексту
  • Не індексуються пошуком

📄 Контентні:

  • HTML <img> тег
  • Частина контенту
  • Семантичне значення
  • Обов'язковий alt текст
  • Індексуються пошуком
🎯 Золоте правило: Якщо зображення важливе для розуміння контенту - використовуй <img>. Якщо просто красиво - background-image!
